\begin{abstract}
Local autoregressive decoding of foundation Large Language Models (LLMs) on multi-core central processing units (CPUs) is fundamentally bounded by the von Neumann \textit{Memory Wall}: each sequential token requires sweeping multi-gigabyte weight tensors across the system memory bus, leaving compute units severely starved. In this work, I present \textbf{SWEEP} (\textbf{S}ingle-pass \textbf{W}avefront \textbf{E}ntropy-gated \textbf{E}xecution \textbf{P}ipeline), an algorithmic and microarchitectural inference framework that overcomes this bandwidth ceiling without pruning, distillation, or accuracy loss. SWEEP coordinates an entropy-gated transition router with AVX-2 assembly kernels to propose speculative candidates, verifying multi-token wavefronts ($K=2$) within a single DRAM memory sweep. By integrating an $O(1)$ zero-penalty KV cache rollback mechanism, SWEEP guarantees \textit{exact mathematical and bit-level invariance} with standard greedy decoding. I perform an exhaustive multi-aspect evaluation on an AMD Ryzen Threadripper PRO 5955WX (16 Cores, 8-channel DDR4) across two premier 7B/8B models: \texttt{Meta-Llama-3-8B-Instruct} (8.03B parameters) and \texttt{Qwen2.5-7B-Instruct} (7.61B parameters). Across \textbf{406 benchmark evaluations} spanning seven canonical suites (GSM8K, HumanEval, MBPP, ARC-Challenge, MMLU-STEM, HellaSwag, BoolQ), SWEEP achieves \textbf{100.0\% bit-a-bit sequence equivalence} (0.0\% regression), while delivering end-to-end wall-clock speedups of up to \textbf{1.60$\times$} (+60.5\%) on coherent text and \textbf{1.23$\times$} on Python code. Microarchitectural profiling demonstrates that the custom AVX-2 assembly kernels execute in $\approx 148\ \mu\text{s}$, consuming less than \textbf{0.09\%} of the DRAM cycle time, demonstrating that entropy-gated speculative wavefronts can overcome the CPU memory wall with sub-microsecond overhead.
\end{abstract}

\section{Introduction}

In generative artificial intelligence, autoregressive transformer inference exhibits extreme memory-bound characteristics during the decoding phase. While the prompt processing (prefill) phase benefits from high compute density via batched matrix-matrix multiplication (GEMM), token-by-token generation is governed by matrix-vector multiplication (GEMV). For an $N$-parameter quantized model (e.g., 4.5~GB for 8B parameters at 4.5~BPW), generating each individual token necessitates reading the entire $4.5$~GB parameter tensor from main memory into CPU registers. 

On standard DDR4/DDR5 platforms, sustained memory bandwidth caps single-sequence CPU throughput to $4\text{--}8$~tokens/s, irrespective of available arithmetic units. Previous attempts to accelerate CPU decoding have predominantly relied on weight pruning, structured matrix sparsification, or lossy distillation. However, such techniques unavoidably degrade reasoning quality, introduce hallucinations in mathematical deduction, and alter output probability distributions.

To surmount this trade-off, I propose \textbf{SWEEP}, an inference paradigm that fuses low-rank latent state projection with entropy-gated batched microarchitectural speculation. The core insight is that while transferring $4.5$~GB of weights from DRAM for a batch size $B=1$ costs $\approx 180$~ms, transferring the same weights for $B=2$ tokens concurrent in a wavefront costs virtually the same $\approx 180$~ms. If the speculative token is accepted, the memory sweep is amortized across two tokens, doubling instantaneous throughput. If rejected, an instant rollback prunes the speculative KV slot with \textit{zero execution penalty}.

\section{Theoretical Architecture}

\subsection{Entropy-Gated Candidate Routing and Latent Projections}
To propose speculative candidates without executing an auxiliary neural network, SWEEP evaluates low-rank projection manifolds while monitoring token predictive uncertainty in SIMD registers. Given a hidden activation vector $\mathbf{x} \in \mathbb{R}^D$, projection activation potentials $\mathbf{v} \in \mathbb{R}^C$ across $C$ structural state centroids are evaluated via compiled AVX-2 assembly kernels:
\begin{equation}
v_c = \text{ReLU}\left( \mathbf{w}_c^\top \mathbf{x} + b_c - V_{\text{th}} \right)
\end{equation}
Simultaneously, the top-$K_{\text{top}}$ normalized logit probabilities $\tilde{\mathbf{p}}$ are scanned in sub-microsecond assembly registers to evaluate Shannon entropy $H$ and the top-two logit margin $\Delta$:
\begin{equation}
H = -\sum_{i=1}^{K_{\text{top}}} \tilde{p}_i \ln \tilde{p}_i, \quad \Delta = \tilde{p}_1 - \tilde{p}_2
\end{equation}
Speculative candidate proposal is dynamically gated: the pipeline dispatches a wavefront token if and only if certainty is high ($H < \tau_H$ and $\Delta \ge \tau_m$). When gated open, a cache-resident hardware CRC32 associative transition router retrieves high-probability continuation tokens in $< 10$~ns, filtered by syntactic structure.

\subsection{Formal Proof of Exact Bit-Level Invariance}

\begin{theorem}[Bit-Level Equivalence]
Let $\mathbf{y}_{\text{seq}} = [y_1, y_2, \dots, y_T]$ denote the output token sequence produced by autoregressive greedy decoding from prompt $\mathbf{x}$. Let $\mathbf{y}_{\text{swp}}$ denote the sequence produced by SWEEP under the same model $\mathcal{M}$ and prompt $\mathbf{x}$. Then:
\begin{equation}
\mathbf{y}_{\text{swp}} \equiv \mathbf{y}_{\text{seq}} \quad \forall t \in \{1, \dots, T\}
\end{equation}
\end{theorem}

\begin{proof}
Let generation be at step $t$ with prefix $\mathbf{s}_t = [\mathbf{x}, y_1, \dots, y_t]$. Greedy decoding emits $y_{t+1}^* = \arg\max_{v} P_{\mathcal{M}}(v \mid \mathbf{s}_t)$.
In SWEEP, candidate token $\tilde{d}_{t+1}$ is proposed. The batched wavefront passes $[\mathbf{s}_t, \tilde{d}_{t+1}]$ to $\mathcal{M}$ simultaneously, obtaining logits $\mathbf{L}_0 = \text{logits}(\mathcal{M}(\mathbf{s}_t))$ and $\mathbf{L}_1 = \text{logits}(\mathcal{M}(\mathbf{s}_t, \tilde{d}_{t+1}))$.
The system extracts $y_{t+1}^* = \arg\max_v \mathbf{L}_0(v)$.

\textit{Case 1 (Speculative Acceptance):} If $\tilde{d}_{t+1} = y_{t+1}^*$, then sequence $[\mathbf{s}_t, \tilde{d}_{t+1}]$ is identically $[\mathbf{s}_t, y_{t+1}^*]$. Because the KV cache and model parameters are deterministic, $\mathbf{L}_1$ is the exact logits tensor for prefix $\mathbf{s}_{t+1}$. The subsequent token $y_{t+2}^* = \arg\max_v \mathbf{L}_1(v)$ is mathematically and numerically identical to the sequential greedy token at step $t+2$.

\textit{Case 2 (Speculative Rejection):} If $\tilde{d}_{t+1} \neq y_{t+1}^*$, the speculative slot at position $t+2$ is purged via \texttt{llama\_memory\_seq\_rm}. The verified token $y_{t+1}^*$ is appended to the output. In the subsequent cycle, evaluation resumes from prefix $\mathbf{s}_{t+1} = [\mathbf{s}_t, y_{t+1}^*]$. 

Under both outcomes, emitted tokens strictly follow the argmax distribution of sequential greedy decoding, guaranteeing bit-level equivalence.
\end{proof}

\subsection{Wavefront Horizon Analysis: DRAM Amortization vs. Core Saturation}

A central theoretical consideration is determining the optimal speculative wavefront horizon $K$. In an autoregressive step verifying a $K$-token wavefront, total wall-clock step latency $T_{\text{step}}(K)$ is governed by:
\begin{equation}
T_{\text{step}}(K) = \max\left( T_{\text{DRAM}}, \sum_{k=1}^K T_{\text{compute}}(k) \right) + T_{\text{router}}
\end{equation}
Because the $N$-parameter weight tensor is streamed across the memory bus only once per wavefront regardless of batch size $B = K$, $T_{\text{DRAM}}$ remains invariant ($165\text{--}195$~ms). On multi-core CPUs, the arithmetic execution time for $K=2$ is $T_{\text{compute}}(K=2) \approx 32\text{--}38$~ms, remaining strictly sub-dominant to $T_{\text{DRAM}}$ ($T_{\text{compute}} \ll T_{\text{DRAM}}$). The additional arithmetic compute is thus completely concealed behind DRAM memory wait states.

However, scaling to $K \ge 3$ triggers two diminishing effects on CPU architectures:
\begin{enumerate}
    \item \textbf{Compound Acceptance Decay:} For a single-token acceptance rate $\alpha$, compound trajectory acceptance scales as $\prod_{j=1}^K \alpha_j \le \alpha^K$. On open reasoning tasks ($\alpha \approx 0.70$), compound probability drops to $\alpha^3 \approx 0.34$.
    \item \textbf{Arithmetic Port Contention:} For $K \ge 4$, multi-token attention projections and KV cache updates approach $T_{\text{DRAM}}$, exhausting ALU execution ports and creating cache hierarchy thrashing.
\end{enumerate}
Consequently, $K=2$ establishes the Pareto-optimal operating point for general-purpose CPU architectures, maximizing throughput gains without introducing computational overhead.

\section{Related Work and Comprehensive Comparison}

Accelerating autoregressive transformer inference without loss of generative quality has emerged as one of the most active frontiers in systems research. Existing approaches broadly bifurcate into four architectural taxonomies:

\subsection{Auxiliary Draft-Model Speculative Decoding}
Pioneered by Leviathan et al.~\cite{leviathan2023} and Chen et al.~\cite{chen2023}, classical speculative decoding pairs a high-capacity target model $\mathcal{M}_{\text{target}}$ with an auxiliary lightweight draft model $\mathcal{M}_{\text{draft}}$ (e.g., Llama-3.2-1B drafting for Llama-3-8B), as implemented in production runtimes like \texttt{llama.cpp}'s \texttt{--draft} mode~\cite{llamacpp}. While highly effective on high-bandwidth memory (HBM) architectures in discrete GPUs, auxiliary drafting collapses on general-purpose CPUs. Because CPU inference is constrained by shared DDR4/DDR5 system bus bandwidth rather than raw arithmetic capacity, generating $K$ candidate tokens with a 1.2~GB draft model requires transferring $K \times 1.2$~GB across the memory bus before the target model is even evaluated. For $K=3$, total memory traffic exceeds 8.2~GB, completely neutralizing speedups and frequently resulting in net throughput regression.

\subsection{Multi-Head and Feature-Level Speculation}
To eliminate the auxiliary draft model, methods such as Medusa~\cite{cai2024medusa}, Eagle~\cite{li2024eagle}, and Hydra~\cite{ankner2024hydra} train multiple auxiliary prediction heads on top of the target model's intermediate representations. Although they avoid loading a separate model, they impose two prohibitive barriers: (1) they mandate extensive supervised fine-tuning or distillation for every target model family, architecture, and quantization scheme; and (2) their candidate trees expand combinatorial verification paths, increasing compute overhead beyond the power budget of commodity CPU cores.

\subsection{Model-Free, Jacobi, and Production Runtime Heuristics}
Prompt Lookup Decoding (PLD)~\cite{saxena2023pld} and REST~\cite{he2024rest} bypass neural drafting by extracting candidate n-grams directly from the prompt text or external retrieval datastores. Similarly, Lookahead Decoding~\cite{fu2024lookahead} uses parallel Jacobi fixed-point iteration to discover n-gram continuations. However, PLD is strictly bound to input-grounded tasks (e.g., document summarization); on open-ended generation, mathematical reasoning, and complex code synthesis, its acceptance rate plummets to near-zero. Furthermore, PLD lacks uncertainty-aware gating, continuing to propose speculative tokens blindly and suffering severe misprediction rollback penalties. Production runtimes such as Intel OpenVINO~\cite{openvino} focus on optimizing dense and quantized SIMD/VNNI GEMV execution paths; however, OpenVINO remains strictly bound to sequential autoregression, requiring an entire DRAM memory sweep for every generated token.

\subsection{Layer-Wise Early Exiting and Entropy Gating}
Frameworks such as LayerSkip~\cite{elhoushi2024layerskip} and SkipDecode~\cite{delcorro2023skipdecode} monitor prediction entropy at intermediate layers to exit early on low-entropy tokens. While sharing the foundational insight that Shannon entropy signals predictive certainty, early-exit methods modify internal transformer representations and introduce statistical perturbations, thereby forfeiting mathematical equivalence with the original model.

\subsection{Hardware Scope: Multi-Channel, Dual-Channel, Discrete GPU, and UMA}
The memory wall governing autoregressive decoding manifests across disparate computing tiers:
\begin{itemize}
    \item \textbf{Octa-Channel Workstation Subsystems (AMD Threadripper PRO 5955WX):} Features 8 DDR4 memory channels ($\approx 204$~GB/s theoretical, $\approx 26.3$~GB/s sustained under GEMV). Memory sweep latency ($165\text{--}195$~ms) dominates execution.
    \item \textbf{Desktop Dual-Channel Processors (Intel Core i5-14600KF):} 14 cores (6 P-cores + 8 E-cores, 20 threads), Raptor Lake architecture. Sequential GEMV is severely bandwidth-bound at 4.19~tok/s (238.6~ms). Wavefront execution amortizes DRAM access to reach 6.67~tok/s ($K=2$, 1.59$\times$), 9.66~tok/s ($K=4$, 2.31$\times$), and \textbf{10.58~tok/s ($K=6$, 2.52$\times$)}, breaking the 10~tok/s barrier on desktop silicon. AVX-2 Top-K Shannon entropy latency is an astonishing 6.72~$\mu$s, with total kernel overhead of only 369.46~$\mu$s ($< 0.1\%$ of the DRAM cycle).
    \item \textbf{Ultra-Low Power Consumer APUs (AMD Ryzen 7 7730U, 15W TDP):} Constrained by 15W notebook thermal limits and dual-channel DDR4-3200 (18.38~GB/s). Sequential decoding is capped at 3.94~tok/s (253.5~ms); wavefront execution reaches 5.54~tok/s at $K=2$ and scales to \textbf{12.67~tok/s ($K=4$, 3.21$\times$)}, breaking the 10~tok/s barrier in compact mobile envelopes.
    \item \textbf{Discrete Blackwell GPUs (NVIDIA GeForce RTX 5070 Ti, 16GB GDDR7):} With 735~GB/s bandwidth and 44.7~TFLOPS compute, single-token GEMV ($K=1$) remains memory-bound at 2.38~ms per 4-layer block (817.2~GB/s sustained). Single-pass wavefront GEMM incurs virtually zero incremental time ($+5.0\%$ latency for $K=4$, $+5.4\%$ for $K=8$), driving effective throughput to \textbf{3.10$\times$ ($K=4$)} and \textbf{5.93$\times$ ($K=8$)} under empirical acceptance ($\alpha=0.75$). Fused warp-level CUDA kernels execute in-VRAM entropy gating in just \textbf{21.76~$\mu$s}, completely eliminating PCIe host roundtrips.
    \item \textbf{Apple Silicon Unified Memory Architectures (UMA):} While M-series architectures feature integrated wide buses ($200\text{--}800$~GB/s), off-chip memory access remains the primary source of thermal dissipation and package energy consumption. Amortizing parameter sweeps directly slashes DRAM interface energy per emitted token.
\end{itemize}

\subsection{Unique Positioning of SWEEP}
As demonstrated in Table~\ref{tab:comparative_taxonomy}, SWEEP occupies a unique and unaddressed Pareto frontier: it operates directly on standard, unmodified GGUF quantization weights; incurs zero auxiliary DRAM traffic; utilizes sub-microsecond assembly-level entropy gating ($80\ \mu$s) and hardware CRC32 routing (817~ns); and guarantees exact bit-level numerical identity with greedy decoding across all evaluated domains.

\section{Conclusion}

SWEEP demonstrates that foundation 7B/8B parameter models can be meaningfully accelerated on commodity multi-core CPUs without modifying weights, pruning connections, or compromising accuracy. By converting memory sweeps into speculative wavefronts and optimizing routing in SIMD assembly, the framework achieves up to \textbf{1.60$\times$ wall-clock speedup} with \textbf{100.0\% bit-a-bit sequence equivalence} across 406 empirical evaluations. Future work will explore expanding wavefront batching to $K=3$ and integrating asynchronous L3 cache prefetching.
